Questions fréquentes

Tout savoir avant de commencer.

Vous avez une question sur le démarrage, les données ou les tarifs ?

Parler à l’équipe ↗
À qui s’adresse ScolaPilot ?

ScolaPilot est conçu pour les écoles privées, de la maternelle au lycée, qui souhaitent centraliser leurs élèves, leurs paiements, leurs notes et leur communication avec les parents.

Faut-il installer un logiciel ?

Non. ScolaPilot est accessible dans un navigateur depuis un ordinateur, une tablette ou un téléphone. Vous n’avez pas besoin d’acheter un serveur.

Peut-on importer nos élèves depuis Excel ?

Oui. L’import Excel est prévu pour vous permettre de démarrer rapidement sans ressaisir toute votre base d’élèves.

Les parents doivent-ils créer un compte ?

Pour les premières fonctions de relance et de reçu, non. Nous pouvons envoyer les informations par SMS ou WhatsApp. Le portail parent sera disponible dans l’offre Premium.

Les frais de messages sont-ils inclus ?

L’abonnement couvre la plateforme. Les frais variables de SMS, de WhatsApp Business API et de transaction mobile money seront affichés séparément pour rester transparents.

Comment fonctionne l’essai gratuit ?

Vous disposez de 30 jours pour tester la plateforme avec votre équipe. Les premières écoles pilotes bénéficient aussi d’un accompagnement de configuration.
